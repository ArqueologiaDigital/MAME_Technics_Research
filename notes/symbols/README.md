# Recovered firmware symbols

Symbol tables for the KN7000 program image, recovered from the firmware's own **MILK-toolkit
reflection tables** — the function names are the manufacturer's, not invented here.

| file | what it is |
|---|---|
| `kn7000_symbols.sym` | `cpu_addr  name`, one per line, plus the verified memory map |
| `kn7000_symbols.inc` | the same set in include form |
| `kn7000_symbols_t4c.sym` / `.inc` | a smaller companion set |

## ⚠ Provenance caveat, read before trusting these

Their own header says *"generated by tools/gen_symbols.py — do not edit"*, **but that generator
is not in this repository**, and a filesystem search did not locate it before these were rescued
(2026-08-17, ahead of a shutdown that would have wiped the only copies, which were in `/tmp`).

So treat them as **recovered data whose regeneration recipe is missing**, not as a build product:

* they are safe to *read* and cross-check against the ROM;
* they should **not** be regenerated or edited until `gen_symbols.py` is found or rewritten;
* if you find the generator, commit it beside these and delete this caveat.

They were rescued rather than left to a reboot precisely because "regenerable" could not be
demonstrated — the cheap, reversible choice under time pressure.
